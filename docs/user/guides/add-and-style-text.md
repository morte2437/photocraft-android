Pick the **Horizontal Type Tool** (shortcut `T`), click on the canvas for a line of text or drag for a text box, and type. Text stays editable, so you can change the words and the style later.

## Add text

1. Choose the **Horizontal Type Tool** in the toolbox, or press `T`.
2. Click the canvas to start a line of text (point text), or drag a rectangle to start a block of text (paragraph text).
3. Type. The text is edited right on the canvas.
4. Set the font, size, leading, tracking, alignment and color with the character and paragraph controls. Each typing session is one **Edit Type** step in the **History** panel.

To switch between the two kinds later, use **Type › Convert to Paragraph Text** or **Type › Convert to Point Text**.

## Edit the text later

Pick the **Horizontal Type Tool** and click the text on the canvas. Text from a PSD that was made in Photoshop stays editable too. If PSD text jumps when you start editing it, update to 0.8.2; see [Text moves when I start editing a PSD text layer](../troubleshooting/text-moves-when-editing.md).

To start new text on top of an existing text layer instead of editing it, hold `Shift` while you click.

## Add a layer style

1. Click the text layer in the **Layers** panel.
2. Choose **Layer › Layer Style**, then an effect such as **Drop Shadow…**, **Outer Glow…**, **Stroke…** or **Bevel & Emboss…**. The **Layer Style** dialog opens.
3. Adjust the effect and confirm.

The other effects in the menu are **Inner Shadow…**, **Inner Glow…**, **Satin…**, **Color Overlay…**, **Gradient Overlay…** and **Pattern Overlay…**. **Layer › Layer Style** also has **Copy Layer Style** and **Paste Layer Style** to reuse a style on another layer, and **Hide All Effects**.

## Turn text into shapes or pixels

- **Type › Convert to Shape** makes vector shapes from the letters.
- **Type › Rasterize Type Layer** turns the text into pixels. After that you can no longer edit the words.
